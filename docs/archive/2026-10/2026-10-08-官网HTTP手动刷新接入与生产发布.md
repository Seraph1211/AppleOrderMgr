## 交付与授权

用户要求以既有 HTTP 方案替换官网爬数、保留订单页手动刷新、把常驻进度卡移入列表顶部图标弹窗，并使用 IPRoyal API。代码接入后，用户明确批准“直接部署生产并验证”。附件技术文档作为实现参考，不将其历史命令视为新操作授权。

- HTTP 执行器替代原手动浏览器执行器；不启动浏览器、不提交 Apple ID 密码。旧自动爬虫不恢复。
- 延续管理员及订单读写权限、选中账号展开、批次幂等和取消。逐单领取、最多五个不同账号并发、共享原 Gate 的限流和尝试历史；只对已知只读网络失败最多三次换出口。
- IPRoyal 官方 API 自动生成中国区粘性代理，kill switch、前后真实出口校验及拒用集合持久化；凭据仅存 root 私密配置，不写入仓库或页面。
- 成功前独立解密并重解析封存 HTTP 证据；仅允许官网状态、观测时间及有依据且原为空的实际取货日期。未知清理或提交进入保护，不自动重放。
- 隐藏常驻“官网更新进度”卡；列表工具栏图标打开弹窗，提交后自动打开，支持空态、失败、分页、取消、焦点约束和 Esc 关闭；关闭后任务继续。
