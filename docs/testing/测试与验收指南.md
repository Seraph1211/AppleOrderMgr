## 验证层级

| 层级           | 可证明                                     | 不能证明                       |
| -------------- | ------------------------------------------ | ------------------------------ |
| 文档检查       | 链接、索引、旧路径、命令及模型字段文档覆盖 | 业务正确性、数据库实际结构     |
| Lint/构建      | 语法与部分规范、打包结果                   | 浏览器业务流程                 |

| 浏览器 E2E     | 指定环境的端到端流程                       | 未覆盖的场景及线上同版本已发布 |
| 生产/业务验收  | 指定版本和范围内的真实结果                 | 其他版本、角色及未测流程       |

## 当前命令

在仓库根目录：

```bash
npm run docs:check
npm run lint
npm test -- --runInBand
npm --prefix frontend run lint
npm --prefix frontend run build
```

`npm test` 默认包含覆盖率。历史 test/test_*.js 中存在会连接数据库、发送邮件或访问官网的脚本，不作为无副作用单测入口批量运行。

## 隔离数据要求

专用数据库、合成数据和明确的生命周期。CLI 读取 DB_NAME_TEST，模型读取 DB_NAME，测试前需显式对齐；隔离 PostgreSQL 与可重复 E2E 环境尚未完成，不能将当前真实开发库当作隔离库。

测试数据覆盖三个角色、不同状态、缺失关联、金额缺失、失败导入、重复订单与渠道特殊字符。历史“6 个渠道、100 个订单”仅为一次生成快照，不保证现在存在。当前没有在本轮运行旧造数脚本。

## 核心验收矩阵

| 功能            | 最少场景                                                                     |
| --------------- | ---------------------------------------------------------------------------- |
| 认证            | 正常登录、错误密码、锁定/解锁、强制改密、三个角色权限                        |
| Apple ID/取机人 | CRUD、枚举、敏感字段不泄露、导出鉴权                                         |
| 导入            | 非法文件、超限、错误行、重复行、过期/跨用户/重复令牌、事务失败与临时文件清理 |
| 邮件            | 来源过滤、已有订单、读状态开关、临时/永久错误、重连、停机与补漏缺口          |
| 官网同步        | URL 身份、返回身份、541/代理失败、取消零数量、并发旧写、金额缺失             |
| 仪表板          | 日期边界、过滤条件、空值、缺失金额、不同币种、异常响应                       |
| 渠道            | 聚合、改名级联、权限、特殊字符、并发，见专项清单                             |
| 列配置          | 可见性保存、恢复默认、损坏数据、新列；排序跨刷新仍是缺口                     |
| 文件            | 上传限制、权限、公开路径、截图存储和导出公式注入                             |
