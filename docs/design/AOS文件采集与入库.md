## 入库与去重

Windows 采集器读取 GUI 配置的本机目录，将完整行先写入加密 SQLite 队列，再通过 HTTPS 设备协议上传。服务器先逐条可靠接收并返回回执，API 内执行器随后按 PostgreSQL 租约处理。订单、来源关联、首次刷新与付款任务登记在同一事务；全局来源切换与设备禁用使用同一个事务锁，订单号仍有独立锁和唯一约束。

重复订单只关联来源留痕，不覆盖订单密码、商品、TAG、联系方式或官网状态。16 列 AOS 的显式姓、名、手机号、身份证后四位唯一匹配且联系邮箱不冲突时关联取机人；历史 15 列缺少尾四位时沿用姓、名、手机号唯一无冲突规则。否则保存来源快照并提示待关联。未登记 Apple ID 不自动创建基础档案，来源 TAG 与档案差异分别展示。Apple 中国大陆官网当前列出的 49 家直营店已按各门店官方页面的 `branchCode` 全量核对并录入；未知门店先保留代码，门店字典未录入核实名称时不猜测。

来源选择默认为邮件。停用来源可继续接收，入库暂停且不消耗重试次数。自动、重试及来源人工入库共用开关；独立人工订单和 Excel 导入沿用原有规则。既有已付款／终态订单的刷新与付款规则不因来源切换改变。

## 当天范围与断线恢复

业务日按北京时间和行内下单日期计算。每个启用设备可在 AOS 模式取得当日服务端许可，采集事件在本地持久化时携带许可 ID。离线事件跨天首次上传仍可恢复，服务器检查许可归属和订单日期，并在最终写订单时再次检查当前来源、设备及订单去重。

文件事件合并约 750 ms，每 5 秒核对补漏，兼容追加、重写、截断和重命名。已登记旧文件的尾行跨日继续处理，未登记历史日期不自动回填。不完整尾行及半个 UTF-8 字符等待后续写入；稳定坏行交服务端人工处理。UTF-8 含／不含 BOM、CRLF、显式 GB18030 可处理；不自动猜编码。服务端固定解析前 15 列，第 16 列为身份证后四位，后续未知尾列只保留在加密原文中，不阻断已知字段。单文件读取上限 64 MiB，单行上传 16 KiB，每批最多 100 行和 1 MiB。

同内容以本机持久化 HMAC 指纹去重，事件 ID 和首次载荷不可变。只有 accepted / already_received 结束上传；响应丢失、网络中断和 429 保持原事件重试，并遵守 Retry-After。永久请求错误留在本机异常队列；业务格式错误正常获得可靠回执后进入服务器人工处理。

切换时固定补录设备范围。采集器把本次扫描的可靠回执与服务器记录关联后才上报完成；服务器核对数量。离线设备仍等待，新设备执行独立首次扫描。邮件切回时按 SINCE 回查已读和旧 UID，并按解析后下单日期限制入库；正常增量游标不倒退。补录完成与业务待人工数分开统计。

## Windows 安装与配置

构建和源代码入口见 [collector/README.md](../../collector/README.md)。交付包为 Windows x64 自包含 `AosCollector.exe`，包含 GUI、托盘和服务运行依赖；不是已签名的生产制品。已在用户确认的 Windows 10 专业版 22H2（19045.6456）完成关键合成验收；其他 Windows 版本和真实抢购软件仍需验证，详见[实机记录](../archive/2026-09/2026-09-10-AOS-Windows实机验收记录.md)。

1. 管理员在网页“订单数据源 → 采集设备”登记设备。服务器以 SHA-256 摘要认证，并使用 AES-256-GCM 密文保存凭证；有设备管理权限的管理员可直接查看或复制，每次查看均记录审计。功能启用前登记的历史设备只有摘要，须轮换一次后才能查看。
2. 在 Windows 以管理员身份运行安装程序，安装到 `%ProgramFiles%\AppleOrderMgr\AosCollector`。后台服务 `AppleOrderMgrAosCollector` 使用 LocalService，开机运行；登录任务 `AppleOrderMgr AOS Tray` 显示托盘。
3. 在网页采集设备页复制“采集器服务器 HTTPS 地址”，再在 Windows“采集配置”填写该根地址、设备名称和凭证，通过目录选择器选择本机普通目录；支持修改、删除和重新选择目录。公网地址来自部署域名或 HTTPS Tunnel，并由服务端 `AOS_COLLECTOR_PUBLIC_URL` 配置；Quick Tunnel 重启后地址可能变化。设备凭证留空时保留现有值。
4. “测试连接与目录权限”从后台服务身份验证连通性和可读权限，再保存配置启动采集。管理员能读取文件不代表 LocalService 能读取；首次安装应在实际目录验证。程序不自动扩大源目录 ACL，不支持共享盘。
5. 关闭窗口只隐藏到托盘；退出托盘后服务继续。明确停止服务才暂停本机采集，本地队列保留。
6. 升级／修复前保存配置并退出托盘。卸载停止并注销服务及登录任务，默认保留程序文件、本地配置和队列，重新安装可恢复。首版不提供自动跨机器迁移队列。

本地数据位于 `%ProgramData%\AppleOrderMgr\AosCollector`；ACL 只允许 Administrators、SYSTEM 和 LocalService，配置、队列载荷和回执使用 Windows DPAPI 机器范围加密。本地通信采用仅本机身份可用的命名管道，不开放管理端口。HTTPS 保留系统证书校验且不跟随重定向；队列有历史记录时禁止直接改到另一服务器或另一设备身份。

## 状态与运维

GUI 分别显示本地待上传／上传异常、服务器今日接收／累计创建／重复／当前待人工与暂停。服务器计数为上次成功同步结果，网络异常时显示连接状态和更新时间；心跳在线、目录健康和订单入库是不同指标。服务器永久错误可从网页查看受审计的原始行、修正草稿、重解析、入库、关闭或关联同号订单。

设备凭证不进入普通列表、日志、配置回显或诊断包；只有设备管理权限可以通过独立接口解密查看并留下审计。默认页面掩码展示邮箱和手机号；原文查看需要管理员敏感权限并记录审计。诊断包只包含服务、目录标签／文件名、计数和稳定错误码。

数据库使用正式 Migration，禁止 sync/alter。当前接入点、字段与权限见 [API 契约](API设计.md#aos-文件入库与数据源切换契约2026-09-10)和[数据库架构](../database/数据库架构.md)。生产迁移和技术发布记录见[本次发布记录](../archive/2026-09/2026-09-11-AOS与付款任务生产发布记录.md)；Windows、真实软件与业务验收见[测试指南](../testing/测试与验收指南.md#aos-文件采集与来源切换验收)。
