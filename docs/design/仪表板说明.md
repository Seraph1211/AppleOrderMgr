## 功能与数据来源

仪表板调用真实 API，展示订单数量、官网订单金额、待处理/待取订单、可用取机人数量、趋势、商品分布和门店分布。页面不内置 Mock；本地验收数据通过受保护的合成数据脚本写入开发数据库。

| 能力     | 接口                                    |
| -------- | --------------------------------------- |
| 汇总     | GET /api/dashboard/stats                |
| 趋势     | GET /api/dashboard/daily-trend          |
| 商品分布 | GET /api/dashboard/product-distribution |
| 门店分布 | GET /api/dashboard/store-distribution   |
| 筛选项   | GET /api/dashboard/filter-options       |

接口参数按[控制器](../../src/controllers/dashboardController.js)接收范围使用；不同图表不保证接收全部筛选参数。

## 当前指标口径

- totalOrders：符合查询条件的订单数。
- totalAmount：官网解析金额之和；缺失不能解释成订单免费，也不能证明所有金额已齐全。
- pendingOrders：pending、processing、ready_for_pickup 三个状态；当前服务会覆盖查询中的 status 条件。
- availableRecipients：取机人表中状态为“使用中”或“未使用”的总数，不受订单日期、状态、型号或门店筛选影响。
- 增长率和日期窗口、商品分布计数以[dashboardService.js](../../src/services/dashboardService.js)为准，跨币种汇总及真实数据口径尚未验收。

## 交互和验证

页面遵循浅色设计，统计卡片属于列表优先规则的例外；加载、错误、空结果需要分别展示。测试时覆盖日期边界、空值、未匹配取机人、部分订单无金额和请求失败。

当前没有在本轮重新执行真实 API/数据库或浏览器验收；历史截图、性能数据不能代表当前版本。[故障排查](../deployment/故障排查.md)提供白屏和接口异常定位方法。
