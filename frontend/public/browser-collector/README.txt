Apple 订单辅助刷新 0.1.2（开发验收版）

用途：在当前 Chrome 中为管理员指定的订单创建临时标签页，正常加载官网并把订单业务字段交回 Apple 订单管理系统。
目前尚未通过真实订单生产更新验收。服务器默认关闭此入口。

0.1.2 修复 `_a=fetchOrder` 详情响应与 541／429 分类；保留失败阶段诊断：仅状态码和数量，不包含请求链接、响应正文、Cookie 或联系资料；权限范围不变。更新已解压版本后，在扩展管理页重新加载本扩展。

安装前请审查权限：Chrome debugger 权限本身较广。当前实现只附加自己创建的临时订单标签页，不读取个人其他标签页或导出 Cookie，不执行付款、取消或登录操作。每笔最多 90 秒、100 个受全局限流控制的请求，结束关闭临时页。当前不支持需要独立子页面的加载，遇到时会停止。

安装：下载 /browser-collector.zip 并解压；在 Chrome 的扩展程序管理页启用开发者模式，选择“加载已解压的扩展程序”，选择包含 manifest.json 的目录。固定扩展 ID 为 oghnhnhheeajagnfjmicoicdpokacdmc。
使用：保持管理台登录，在“订单管理”指定行点击“浏览器刷新”。只有收到官网有效详情并通过服务端身份与版本校验后才更新订单。浏览器退出、官网拒绝或超时会保留旧订单数据。
卸载：在 Chrome 的扩展程序管理页移除“Apple 订单辅助刷新”。

仅允许 https://apple.godp.me 和本地 5173 开发页面发起任务。管理台登录令牌和任务票据不会传给扩展；扩展只接收指定订单原始链接、订单号和截止时间。回传前剔除访客令牌、个人联系信息及原始 HTML。
