## 需求与实现

按用户确认，将原多候选下拉选择改为全部序列号的待绑定列表。每行支持修改和删除，统一显示订单号与保留数量，点击“确认绑定 N 台”提交全部保留项。删除仅移除待确认项，不解除已登记设备；空列表、无效格式、重复序列号禁止提交。未识别时仍可手动填写。

复用原有单设备幂等绑定接口逐项保存，无 API 或数据库变更。成功项进入已登记列表并从待确认项中移除；部分失败显示每项原因，仅保留失败项供修改、删除或重试。保存期间禁用编辑、删除、图片重选、返回和关闭按钮，防止重复操作。原条码扫描自动绑定行为保持。
