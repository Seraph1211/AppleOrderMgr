## 发布内容

API 从 `apple-order-mgr-runtime:20260920-order-mail-html-api-amd64` 增量升级到 `apple-order-mgr-runtime:20260921-browser-batch-amd64`。核对当前生产全部业务源码摘要后，只叠加 9 个必要文件：浏览器刷新 Router／Controller、短期票据、结果字段白名单、浏览器取数校验、预算与可取消的全局许可，以及现有 `crawlerService` 中的浏览器分支、版本核验、随机票据防重放和审计。旧 HTTP 重试、Provider、Worker 调度等未发布改动没有夹带。生产源码增量保存在制品 `api-increment.patch`，不是直接发布整个脏工作树。

`images.override.yml` 只为 API 启用 `BROWSER_ORDER_REFRESH_ENABLED=true`。默认扩展仍为 120 秒票据／90 秒采集，`isolated_batch` 为 330／300 秒。十并发执行器运行在本机，源码与独立客户端包保存在本地制品 `local-client/`；没有在服务器启动 Chrome 或十并发抓取进程，也没有新增管理台批量入口。

只重建 API 容器；各 Worker 的镜像、容器 ID、启动时间及重启计数不变。前端从当前 `20260920-orders-system-id` 发布目录原样继承，所有前端文件及公网首页摘要一致；共享 `app.env`、`order-mail.env` 摘要不变。没有 Migration，没有改 Nginx、PostgreSQL、邮件账号、代理套餐或其他应用。
