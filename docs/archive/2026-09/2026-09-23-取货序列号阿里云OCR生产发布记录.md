## 功能与授权

取货记录的“设备扫码”新增“拍照 / 图片识别 Serial No.”，支持手机拍照和选择图片。后端调用阿里云全文识别高精版 `RecognizeAdvanced`，仅返回序列号候选；由操作人核对、选择或修改后，使用原绑定接口保存至当前订单。多候选不自动选定，不修改既有条码自动绑定、解除、订单管理展示和搜索规则。不保存识别图片或完整 OCR 文本。

用户明确批准后付费开通、网站每月最多 1000 次及生产部署；完成账号安全验证并亲自创建 AccessKey。独立 RAM 用户 `apple-order-pickup-ocr` 无控制台登录权限，仅绑定自定义策略 `AppleOrderPickupOCRAccess`，策略只允许 `ocr:RecognizeAdvanced`、资源 `*`。凭据保存于 Git 忽略的本地 `.env` 和生产共享 `app.env`，文件权限 600，不进入前端、代码或日志。

额度通过 PostgreSQL `ocr_monthly_usage` 按北京时间月份原子预占，所有用户共用网站上限。每用户每分钟最多 10 次；供应商失败仍保留计数，不自动重试。阿里云免费额度由账号共享，网站上限不代表费用为零。
