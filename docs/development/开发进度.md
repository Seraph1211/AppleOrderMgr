## 🔧 2026-09-05 - 全项目审查与第一批基础修复

### 已完成（当前本地工作区）

- 新增并完善 `docs/planning/项目优化计划.md`，补充已实现功能、完整度、审查结论、分阶段任务、验收标准和付款人/内部结算演进方案。
- 修复取机人身份证密文被 Sequelize 格式验证误判的问题，改为从 getter 明文派生后四位和盲索引。
- 修复安全迁移后旧触发器用密文尾部覆盖 `id_card_last4` 的问题，并让存量迁移显式写入明文派生值。
- 修复 Sequelize 关联使用数据库字段名，导致隐式生成重复模型属性的问题。
- 业务 API 统一在应用层执行认证和强制改密检查；系统日志与自动刷新控制限管理员访问。
- 修复临时锁定到期后账号状态未恢复、已签发 token 却立即被拒绝的问题。
- 密码哈希改用 `bcryptjs`，移除本机 x86_64 原生 `bcrypt` 在 arm64 环境下阻断模型加载的问题。
- 修复取机人导出未携带 JWT 且硬编码 `localhost:3000` 的问题。
- 移除仪表板默认 Mock 数据与渠道“每单 8000 元”估算，金额统一使用官网解析字段；修正产品统计 SQL 错误字段。
- 邮件监听增加生产发件人白名单、显式已读开关，修复单封邮件重复完成回调、主动停止后误重连和异常重复重连。
- 爬虫增加 Apple URL 与官网返回订单号双重身份校验，将网络抓取移出事务，并在短事务内锁行、拒绝并发旧结果；取消订单数量为 0 时保留邮件权威数量。
- 独立爬虫 Worker 拓扑不再由 Web API 伪造运行状态或内存恢复成功，状态改为日志观测，恢复操作明确返回 409 并给出运维动作。
- 渠道订单统一脱敏手机号并隐藏 Apple 订单链接；独立 `/orders/:id` 页面移除演示数据，接入真实详情 API。
- 顶栏不再硬编码“邮件监听中”，在心跳接口完成前明确显示“邮件监听状态未接入”。
- 新增 `docs/archive/2026-09/2026-09-05-项目现状审查与修复报告.md`，记录完整功能盘点、架构演进理由、修复/规划/未验证边界、隔离数据库条件和付款结算模型。
- 更新数据库和 API 权威文档中与本批修复相关的契约。
