# 仪表板说明

> 状态：2026-09-23 基线已生产发布；2026-09-25 的 `picked_up` 邮件推定筛选及已付款统计仅本地实现，未发布或作生产业务验收。
>
> 适用范围：仪表板页面及 `/api/dashboard/*`；生产发布单独记录。

## 筛选与指标

- 下单日期使用 `orderDate` 的北京时间完整日，默认近 7 天，支持单边范围和清空。
- 订单状态筛选继续使用邮件状态：待确认、订单已确认、处理中、可取货、已取货；订单管理页按时间派生的“已过期”不进入仪表板邮件状态筛选。商品复用独立商品筛选键，展示完整型号、颜色、容量；取机人 TAG 复用订单列表展示 TAG 的来源回退顺序。三个维度支持多选，组内 OR、跨维度 AND。
- 所有订单卡片、趋势、商品及城市分布使用同一筛选和 `orderAccess` 权限范围。候选同样服从权限，并排除自身维度的已选条件，保留其他筛选。
- **订单总数**：筛选后的去重订单数。
- **已付款订单数**：筛选结果中 `emailOrderStatus` 为 `processing`、`ready_for_pickup` 或 `picked_up` 的订单数，与已选状态取交集，不使用人工付款任务状态。
- **订单总金额**：筛选订单的整单 `orderAmount` 之和，沿用官方售价映射；无金额订单不计入合计，并展示待售价确认数量。商品筛选不将整单金额拆成单品金额。
- **可用取机人**：取机人档案中状态为“使用中”或“未使用”的人数；选中 TAG 时按档案 `tag` 精确匹配多个 TAG，无 TAG 时统计全部。日期、状态、商品不影响此指标，沿用原有独立基础档案统计权限。订单 TAG 与档案 TAG 不同的情况下，两类指标分别按各自规则匹配。

## 图表

- 视觉沿用原页面浅灰背景／白色卡片，四卡图标依次蓝、橙、绿、紫；趋势线为 `#8B5CF6`，饼图色序为紫、靛蓝、蓝、青、绿。

- 趋势按北京时间下单日统计订单数，范围内没有订单的日期补 0；超过 3660 天的宽范围仅返回实际日期点，缺失下单日期不进入趋势。标题随所选日期变化。
- 商品分布按完整商品筛选身份归组，名称归一化规则复用订单管理页，不按商品数量加权。一个订单同款多件／重复明细只计一次；一单含不同商品时可分别计入多个分组，因此商品分组订单数之和可能大于订单总数，饼图占比以分组计数之和为分母。展示筛选后订单中的全部商品，不截断前 10 项。
- 城市分布使用订单取货门店和现有 `pickup_stores` 字典；邮件门店优先，无邮件门店时用订单门店代码，再用订单门店名称。名称只归一化 Apple 前缀、空白和标点，不做模糊城市猜测；未知／有歧义门店计入“未知城市”，不读取取机人居住城市。每单只计一个城市，分布合计等于订单总数。
- 无结果、加载、错误分别展示；快速切换条件时旧响应不得覆盖新结果。长商品名完整可读，手机不横向溢出。
