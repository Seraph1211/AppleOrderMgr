## Main 代码 Review 与修复闭环

- API Token使用32字节随机值、SHA-256鉴权和AES-GCM加密取回，令牌与用户绑定、90天有效，撤销与权限变更实时生效。管理员不能读取他人Token。
- 请求与日额度在数据库事务内原子预占；员工更换Token不清零，跨进程共享限额。日额度仅限API新供应商调用，复用不计日额度，既有单人／Excel不增加100次日额度。
- PostgreSQL共享执行锁限制单在途及500ms起点间隔，后台与API共享暂停；未知结果持久保护、不得自动重试，管理员处置必须说明原因并保留审计。
- Main发现并推动修复SQL命名占位符边界、大小写／编码路径日志绕过、404回显查询串、Nginx location解析前的错误头遗漏、旧页面暂停状态与按钮不一致、前后端处置原因长度不一致等问题；独立复测覆盖。
- Nginx只对本站实际配置局部补丁：无query/referrer访问日志，虚拟主机错误日志关闭以避免原始请求行泄漏，应用保留受控结构化诊断。HTTP直接拒绝，GET不缓存，上游不自动重试。此改变减少该虚拟主机原始Nginx错误明细，排障使用请求编号与应用日志。
- 正式Migration新增5表及批次关联字段；down在已有API历史时拒绝，生产回退仅回退代码并保留结构、用量和审计。
