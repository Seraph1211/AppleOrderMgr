## 发布内容

公开报价定位由 iPhone 18 单代产品调整为 Apple 全系通用入口。页头显示“Apple 报价”，主标题显示“Apple 实时报价”，删除产品范围、人民币计价和“页面仅展示对外报价”等辅助文案，只保留报价更新时间。当前来源数据仍为 iPhone 18 Pro／Pro Max 28 款，后续其他 Apple 产品继续使用同一入口。

前端新增 `/quote/apple`，旧 `/quote/iphone18` 自动跳转至新地址；公开 API 新增 `/api/public/apple-quotes`，旧接口作为兼容别名保留。后台返回的固定公开路径同步改为 `/quote/apple`，管理页标题改为“Apple 报价管理”。

## 构建与发布范围

以当前生产源码归档为基线，仅覆盖 6 个报价相关源文件，构建 Linux/amd64 API 镜像和前端静态制品。全部上传文件通过 SHA-256 校验，镜像内的新 API 路由、后台公开路径和前端新标题均在切换前核对。

本次没有 Migration、数据库写入、环境变量修改或来源账号变更。只重建 API 容器并原子切换前端指针；邮件、订单邮件和企微 Worker 的镜像及容器 ID 保持不变，Nginx 配置检查通过且未重启。
