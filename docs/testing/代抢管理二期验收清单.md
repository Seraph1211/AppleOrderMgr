# 代抢管理二期验收清单

> 状态：当前有效
> 最近核对：2026-10-15
> 基线：二期需求与实施方案及本次实现工作树
> 适用范围：独立隔离测试，不授权生产写入、真实 Apple 抢购或外部软件任务

需求依据：[二期方案](../planning/代抢管理二期需求与实施方案.md)。本清单保存可复用预期，一次执行结果见[独立验收报告](../archive/2026-10/2026-10-15-代抢管理二期独立验收.md)。

## 隔离和证据

- 只操作主 Agent 指定的独立 Compose 项目、端口和 PostgreSQL；不操作默认开发容器、生产库或真实官网。
- 数据库用例显式检查运行开关、测试库名称和空 `DATABASE_URL`；正式 Migration 建库，不使用 `sync/alter` 代替。
- 浏览器合成 API 与真实 PostgreSQL/API 分开计数；截图检查桌面和 375px 窄屏，自动定位通过不等于目视通过。
- 所有客户、账号、密码和订单为合成。日志与报告不输出模板密码或客户原文。

| TP-01 | 模板       | 9种支付逐项对照软件值；19商品组合逐项对照软件完整名称；49门店代码逐项对照截图名称。                                                      |

| DB-02 | 真实数据库 | 并发自动分配、手选及追加不双占；池外/异常/已用账号不可自动占用；确认外部软件停止才释放；结束状态不自动释放。                             |
| DB-03 | 真实数据库 | 人工四态任意互转，成功通过说明/原备注/默认人工确认保留审计，不强制额外表单；事件记录操作人、时间、前后状态及来源；客户备注不被原因覆盖。 |
| DB-04 | 真实数据库 | 同委托自动关联两个匹配 Apple 订单；同订单不能跨委托；重复匹配幂等；不要求付款；官网取消不回退。                                          |
| DB-05 | 真实数据库 | 人工恢复待处理/抢购中后旧关联不触发成功，新关联可触发成功；取消时新关联只补记录；修改备注不变状态。                                      |
| DB-06 | 真实数据库 | 人工关联可记抢错商品，仍核对账号及客户；解除保留历史、原因和拒绝重连；编辑不改 Apple 订单和分配历史。                                    |
| DB-07 | 真实数据库 | 自动匹配逐项拒绝账号/时间/姓名/手机号/证件尾号/邮箱冲突/商品组合/数量/门店不足；备注不参与匹配。                                         |

| AU-02 | 真实 API   | 列表、详情、账号池不返回密码；明确复制可返回密码且 no-store；原文加密、审计脱敏。                                                        |

| UI-02 | 浏览器     | 状态/备注保存、取消、失败保留输入；四态任意恢复，无额外强制重抢表单；人工成功原因入口；复制及池管理可达。                                |
| UI-03 | 浏览器     | 多订单列表系统ID、Apple号、商品、官网状态及观测时间；缺失显示未获取，不冒充邮件状态；长文本/横滚/窄屏操作可达。                          |
| RG-01 | 检查       | 后端 lint/完整 Jest/docs:check、前端 lint/build；独立用例不替代开发自测和主 Agent Review。                                               |

## 边界

真实外部软件导入、软件执行顺序/停止行为、真实手机软键盘、真实 Apple 下单付款与生产验收必须单独记录，不能由合成模板或浏览器结果推断通过。
