## 故障与根因

公开页面提示“报价数据暂不可用”，API 返回 503 `QUOTE_SOURCE_UNAVAILABLE`，但 API 与数据库健康。日间修复虽然取消固定 28／12／16 数量，却仍要求两种型号齐全且同型号各容量颜色集合一致，错误地把来源实际商品组合变化判为损坏批次。

只读核对 MySQL 最新批次为 2026-09-29 21:16:40：Pro 16 款、Pro Max 9 款，共 25 款；批发价 NULL 3 款、官网价 NULL 9 款。直接请求明威实际页面确认 Pro Max 就是 9 款，其中 256GB 冰川蓝、512GB 银色和冰川蓝显示“电询”；官网列 0 被爬虫规范化为 NULL。因此这次不是爬虫漏写，不能补回旧商品或沿用旧价格。此前用户核对的 512GB 冰川蓝 13,300 元，当前来源已改为电询。

另外，报价来源层使用 `Number(null)` 会把未报价转成 0，若仅删除组合校验会产生错误低价。因此同时修正空价格链路。

## 修复范围

- 不要求固定总数、两种型号同时出现或各容量颜色集合一致；最新批次按实际商品列表展示。
- 来源保留 NULL；数字字符串正常解析，空值／空白／来源 0 表示暂无数字价格。非法数字、负价、空批次、重复或无效身份仍拒绝。
- 基价为空时不计算调价，公开与管理端显示“暂未报价”；官网价为空显示“—”；复制同样使用文字，不显示误导性 0 元。
- 调价规则和人工展示顺序不变，数字基价恢复后自动计算，不回退历史报价、不补回来源移除商品。
- 更新 API 契约、设计说明和回归验收。PPSpider、生产数据库和公开开关均未修改。
