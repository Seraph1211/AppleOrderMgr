## 设计方向

沿用此前确认的灰白工作台与品牌蓝，采用 Framed sheet（框架面板）结构，方向种子 `1778040491`，未重新抽选。让筛选与采集状态退居辅助层，日志原文成为页面主体，方便回答“所选服务器与实例中，目标账号刚才发生了什么”。

1. 按生成图参考（本地证据：`output/log-query-ui/2026-11-01-紧凑图本地预览/00-生成图参考.png`）实现紧凑工具栏：服务器约150px、实例176px、账号110px、日期时间合并框202px、关键词弹性加长到约294px（1440px窗口），查询／重置／更多筛选紧随其后；宽屏32px高，按内容定宽，移除两行大表单及其外层卡片。在1440px和1265px默认条件下保持单行，手机自然换行、44px触摸高度。侧栏和阅读工具区在副本中按参考图对齐。
2. “全部账号”在日期左侧，范围共用一个工具栏入口，展开后左右两组分别为“开始日期时间”和“结束日期时间”。每组内日期输入与秒级时间输入紧邻，并拥有自己的日历、月份和选中日期；不再把时间放到面板底部，也不在选日期后自动切换另一端。两组可分别键入或点选；修改一组不改变另一组。窄屏上下排列完整端点组，浮层内部可滚动。取消／Esc丢弃草稿，倒序时禁止确定，确定后仍需点击查询应用。成组交互截图（本地证据：`output/log-query-ui/2026-11-01-起止日期时间分组/11-起止完整日期时间-1440.png`）。

   保留[shadcn/ui日期时间组合](https://ui.shadcn.com/docs/components/radix/date-picker#time-picker)的视觉方向。新增需求为连续区间，例如北京时间 `2026-10-23 16:23:55` 至 `2026-10-25 12:23:20`：包含10月23日开始点之后、10月24日整天及10月25日结束点之前的日志，不得将相同起止时刻分别套用到每天。结束时间延续既有按秒包含的口径，包括结束秒内毫秒记录。

3. 工具栏始终显示，不再提供整区收起；“仅未识别账号”放入“更多筛选”浮层。勾选后暂时禁用账号输入，点击查询生效，重置恢复；更多筛选截图（本地证据：`output/log-query-ui/2026-11-01-起止日期时间分组/10-更多筛选-1440.png`）。查询和刷新不会让工具栏消失。
4. 日志采用等宽原文、行序号与浅色选中提示，保留换行、关键词高亮和异常解析标记；序号为列表位置，原始文件和行号在详情中查看。
5. 复制、上下文、专注阅读和刷新使用统一图标按钮。详情按用户提供的线上通栏排版，宽屏占视口约81%，到顶到底、取消外部留白和圆角；900px以下全屏。顶部仅保留48px标题栏、该账号／整个实例切换及一行简短提示。原先默认展开的文件信息、独立“选中原文”块及重复的上下文小标题移除；文件时间／账号／文件名／原始行号／版本和异常字节收入标题旁的信息按钮，按需浮层查看，不挤压阅读区。选中原文在上下文中直接浅蓝标记，初次进入居中定位；提供定位、复制及自动换行。正文使用原始文件行号、等宽原文、独立细滚动条，前后边缘可继续加载、追加去重、向前追加保持阅读位置；加载和失败反馈留在正文区。手机收短标题操作，保留44px触摸目标和全屏阅读。短屏效果（本地证据：`output/log-query-ui/2026-11-01-上下文阅读优化/01-上下文阅读-1265.png`）、手机效果（本地证据：`output/log-query-ui/2026-11-01-上下文阅读优化/01-上下文阅读-390.png`）、按需来源（本地证据：`output/log-query-ui/2026-11-01-上下文阅读优化/02-按需查看来源-1440.png`）。
6. 采集状态改为紧凑提示，展开后显示既有细节；待上传为零不代表日志完整性已获证明。保留追加加载与错误重试。
7. 标签管理统一为轻量表格弹窗，保留逐行编辑、保存、清空与版本冲突逻辑；手机输入框和保存操作同屏可见。

## 正式接口差距与下一步

当前[真实日志API](../deployment/AOS日志API使用指南.md)仍按单一 `date` 加 `fromTime`／`toTime` 查询，不能将本地演示称为真实跨日能力已完成。本轮仅在隔离mock中增加 `endDate` 并执行连续时间区间；未修改权威API契约、正式控制器、数据库或生产服务。

正式开发需补跨日查询、同区间账号候选、过滤条件绑定游标、跨日排序／追加去重和边界验收；未知原始时间不能冒充精确区间内的记录。范围交互已获确认；正式开发按完整需求在最新业务基线上核对并补齐契约与实现。
