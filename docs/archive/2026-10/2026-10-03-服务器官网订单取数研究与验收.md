## 方案发散与有效路径

- 官方订单列表：Apple 帮助明确支持账号登录查看订单，但访客订单可能未关联。1196 列表有目标；1209、1273 登录后列表没有目标，不能把空列表当成成功。[查看订单](https://www.apple.com.cn/shop/help/viewing_changing_orders)、[账户与访客订单](https://www.apple.com.cn/cn/shop/help/your_account)。
- HTTP 访客表单：使用当前页面真实表单和会话参数，仍出现 541；没有据 HTTP 200 加载页判定取数成功。
- 直接浏览器查单：前期出现 541、代理隧道错误及驱动问题，全部保留失败。
- 有效组合：服务器有界面 Chromium/Xvfb 正常执行官网页面，从账户中心完成 IDMS → 商店登录；关联订单可跟随列表详情，未关联订单则在服务器会话中打开已有 `/xc/cn/vieworder/…` 链接，最终由 `orderx/guestx` 的 `fetchOrder` 返回完整 JSON。没有关联订单、修改账号或进行支付动作。
- 服务器会话复用：AES-256-GCM 保存，账号绑定、时效和域名检查；每次使用全新浏览器进程，缓存禁用，必须重新获得官网响应。仅保存会话不代表订单已成功。
- App Store Server API 面向数字商品交易，不能作为这些实体硬件订单的数据接口。既有邮件解析仅用于来源对照，不作为本轮官网结果。

国内网帆现有隧道套餐验证有效。亦优已通过官网控制台生成国内单 IP 参数并使用现有额度，IDMS 曾成功但商店交接 541，另一次短效端点隧道失败。神龙国内站停留在未登录入口，无现成会话，未采购或创建账号；已有有效国内路径后没有把它当作阻塞条件。网帆套餐核对到期为 2026-10-09 14:21:36，该时效不代表长期可用保证。

## 验证与生产隔离

83 项专项测试通过，覆盖身份与完整商品集合、访客 JSON、非官方目的地、密码发送边界、CDP 取消竞态、断开／超时、密文篡改、会话串号／过期、持久化预算、次数和冷却。五个新增模块整体行覆盖率 79.47%、语句 77.66%；解析器行覆盖率 96.84%，限流器 90.82%，支持模块及 CDP 100%。浏览器启动与真实 Apple 交互另由上述真实运行验证，不能用 Mock 代替。

全量后端回归 86 套／988 项通过，26 套／359 项按真实服务条件跳过；新增 JS Lint 0 错误／0 警告，格式检查、Shell／Python 语法及文档检查通过（185 份全部可达、66 个模型字段覆盖）。开发镜像依赖落后于仓库，首次全量检查有五套缺模块；镜像重建拉取基础镜像超时，最终在原开发容器只读挂载本机完整 node_modules 与当前锁文件后重跑通过，没有修改锁文件或生产依赖。最终 12 份服务器执行源码／迁移文件与本地 SHA-256 逐一核对；最后的阈值常量整理保持运行参数不变，官网原文另经最终解析器离线复核。
