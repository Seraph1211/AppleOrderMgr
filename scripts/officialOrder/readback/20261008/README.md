# 官网订单独立回读冻结源码

此目录保全生产 `confirmed-dates-v2` 的 10 个源码文件及原 `manifest.json`，于 2026-10-08 从服务器只读取得，逐文件 SHA-256 与清单一致。没有复制订单输入、代理账号／口令、Cookie、密钥或业务证据文件。

入口为 `official-original-scope-progress-v7.py`，从同目录加载 `official-independent-readback-with-receipts-v2.py`，并依赖同目录的历史日期／付款／四单确认日期链模块。保留原文件名及内容以便与生产清单比对；这些是既有发布源码，不是新建的通用 SDK。

这是固定 489 单批次的受控工具快照。代码包含生产根目录、API 容器名及固定案例约束，运行需要原私密计划、证据、研究状态和受控权限；仅复制源码不意味着可在本地直接验收生产数据。默认参数不是开发环境参数，维护时不要直接运行采集／回写入口。

`applyConfirmedDates.py` 与 `applyConfirmedPickupDates.js` 是已经执行的四单日期专用工具，随清单保全，不代表新增执行授权；原生产意图已 APPLIED，不应重放。根目录采集、状态／日期事务脚本与这里的冻结快照分别维护，修改快照会使原清单不匹配。

现行操作与源码同步边界见[运维手册](../../../../docs/deployment/服务器官网订单取数.md)。通用化配置、统一回读 CLI 和专用案例协议仍待实现。
