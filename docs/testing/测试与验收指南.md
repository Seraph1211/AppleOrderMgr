## 当前命令

在仓库根目录：

```bash
npm run docs:check
npm run lint
npm test -- --runInBand
npm --prefix frontend run lint
npm --prefix frontend run build
```

`npm test` 默认包含覆盖率。历史 test/test_*.js 中存在会连接数据库、发送邮件或访问官网的脚本，不作为无副作用单测入口批量运行。

## 隔离数据要求

专用数据库、合成数据和明确的生命周期。CLI 与模型都必须显式指向同一个临时 `DB_NAME`；验证完成后只删除精确命名的测试库，不能将当前开发库或生产库当作隔离库。

测试数据应覆盖三个角色、不同状态、缺失关联、金额缺失、失败导入、重复订单与渠道特殊字符。历史“6 个渠道、100 个订单”仅为一次生成快照，不保证现在存在。

本地页面验收可使用 `npm run db:seed:local-mock` 对应的受保护脚本。它只在显式设置 `ALLOW_LOCAL_MOCK_DATA=true`、`LOCAL_MOCK_USER_PASSWORD`、`NODE_ENV=development` 且数据库主机为本地目标时运行，生成 8 个 Apple ID、20 个取机人、48 个订单、3 个 Mock 工作人员和 30 个付款任务，并为部分订单填写合成的外部付款人姓名；其中 16 个取机人状态为“使用中”或“未使用”，付款任务覆盖四种处理状态、24 个已分配和 6 个待分配场景。付款人不建立登录账号；脚本可重复执行且不读取生产数据，只重置 `mock_pay_*` 合成员工账号的密码，不能在生产或共享数据库运行。完整 Compose 命令见[本地开发指南](../development/本地开发指南.md)。

## 结果记录

### 依赖更新回归

SheetJS 来源更换时执行 `npm run security:verify-vendor` 与 `test/excelDependency.test.js`，验证真实库的模板／解析／导出行为及上传、会话、权限边界。该套件使用临时文件、回环 HTTP 和模型桩，不证明真实数据库事务回滚；数据层另按隔离数据库层级验证。

前端路由和构建依赖更新时，可在专用空白 Chrome 上运行 `npm run test:browser:lifecycle`。脚本使用 Playwright Core，要求显式 `RUN_LIFECYCLE_BROWSER=true`、专用 `LIFECYCLE_BROWSER_WS`；`LIFECYCLE_BROWSER_URL` 默认为 `http://127.0.0.1:5173`，仅接受 HTTP 回环地址。所有业务 API 被合成响应拦截，其他外部请求阻断，禁止连接用户日常浏览器。它验证页面、路由和权限展示，不代表后端鉴权、真实登录或官网验收。

每次验收记录日期、版本、环境、用例、通过/失败/阻塞、证据位置和未验证范围。可复用用例保留在本目录；有日期的执行结果进入 archive，开发进度链接最新证据。HTTP 200 和静态通过不能替代人工或生产验收。

### 收信时效修复的分层测试

- `emailScanner.test.js` 验证计时、UID 进度与连接取消；`emailServiceLifecycle.test.js` 验证可靠接收、业务处理和已读确认边界。
- `emailScannerProtocol.test.js` 使用真实 node-imap 和仅监听 127.0.0.1 的合成 IMAP 服务器，验证 UIDNEXT=0、已读通知、BODY.PEEK 和真实正文事件顺序，不访问真实邮箱。
- `emailScanProgress.integration.test.js` 通过 RUN_EMAIL_DB_INTEGRATION=true 显式启用，要求 DB_NAME 以 test_email_scan_ 开头的专用可丢弃库；验证迁移 down/up、并发游标、健康指标及 received 恢复。不得指向开发主库或生产。

- `test/officialOrderLifecycle.integration.test.js`：在门控隔离库验证历史重校验默认只读，执行只改校验字段、保留所有业务数据和时间字段，重复执行无变化；批量后续写入失败时全部回滚。执行方式沿用该文件的 `RUN_LIFECYCLE_DB_INTEGRATION` 与固定隔离库保护，不连接业务库运行。

### 代理重启与付款分配回归

- 切换失败后冷启动：有最后有效 Provider 时恢复并验证，保留候选失败诊断并继续领取；无可恢复配置／恢复失败时公开阻塞、保留队列、限制一分钟内重试；并发新切换请求不可被旧恢复覆盖。
- workerReady 必须同时满足当前实例初始化、心跳有效且未暂停；仅有历史 activeProvider 或心跳不足以显示就绪。
- `officialOrderLifecycle.integration.test.js` 覆盖恢复到领取、官网截止落库、自动分配及正式 Migration 回退升级。真实生产新单与官网重试结果单独记录。
- 付款已过期但 deadlineAt 为空的两张付款页面显示“付款已过期”；待付款且无截止仍等待官网时间，不假定邮件时间是付款截止。

## 刷新队列持续补位回归

`test/refreshWorkerConcurrency.test.js` 覆盖慢任务期间晚入队任务可启动、20 个名额用满后不超领、释放后只补空位、重叠 tick 不重复领取、持久化失败释放内存名额、暂停与代理切换排空边界，以及退出时等待领取与持久化完成。`test/officialOrderLifecycle.integration.test.js` 在限定隔离 PostgreSQL 中验证两个任务同时 running、本 Worker 续租及其他过期租约恢复。真实生产验收需记录第二单开始早于第一单结束的时间证据；只看配置值或健康检查不足以通过。

## 付款页面分页与批量刷新回归

`npm run test:browser:payments` 使用 `PAYMENT_BROWSER_WS` 指向专用临时 Chrome；所有 API 使用合成数据拦截，不能指向日常浏览器。`PAYMENT_BROWSER_OUTPUT` 可指定截图目录。验证两页分页、10/20/100 条切换、页码跳转、筛选归一、空结果、当前页全选与翻页清空、官网下单时间及未知值、本人权限隐藏、排队／执行／终态、批量部分失败与重试、草稿保留、刷新或保存期间翻页及总数缩减退页、375px 横向滚动。它不证明生产 API 鉴权或真实官网成功率。

`accessControlPayment.integration.test.js` 在既有门控隔离库中新增 150 单分页覆盖、组合筛选总数、末页无重漏、空页及非法参数、本人任务归属和下单时间；不得在业务库运行。开发容器若仍绑定旧镜像，应通过 `docker compose -f docker-compose.dev.yml run --no-deps --rm -T api ...` 使用与锁文件一致的当前开发镜像执行，不能将旧依赖失败当作本次业务回归结果。


### 下单时间回归

`test/orderTime.test.js`、`test/orderControllerFilters.test.js`、`test/dashboardOrderTime.test.js` 验证来源精度、日期筛选与导出；官网生命周期隔离库用例验证“解析→合并→持久化→恢复→再次刷新”不丢失时分秒。付款浏览器脚本支持 `PAYMENT_BROWSER_TIMEZONE=UTC`，验证跨时区仍展示北京时间且日期值不补造时间。真实历史恢复仅依据来源快照，不代表官网精确下单时间验收。

### 账号管理与单设备登录回归（2026-09-09）

使用 `RUN_ACCOUNT_INTEGRATION=true` 执行 `test/accountManagement.integration.test.js`，`DB_NAME` 必须匹配 `apple_order_mgr_accounts_test_数字`，且先执行正式 Migration。测试仅用合成账号与独立 HTTP 服务，不启动邮箱或爬虫。最后的 Migration down/up 会清空新增会话和操作记录，禁止使用开发主库或生产。

- 首次登录及历史强制改密标记不阻断访问；首页与导航顺序一致，零权限进入个人设置。
- 每个账号只能保留一个会话；第二端须确认，取消保留旧端；并发首次登录／接管只能成功一次；过期／重放确认凭证不能绕过确认。
- 退出撤销服务端会话，迟到的旧端退出不撤销新端；旧版本 Token 和到期会话拒绝访问。
- 管理员、操作员和只读账号均可修改本人昵称、密码；资料接口拒绝角色／身份等额外字段；管理员可配置昵称和重置密码，普通账号不能重置他人密码或读取日志。
- 重置／本人改密后旧 Token 失效，账号列表不暴露密码、哈希及会话 ID；操作日志保存身份快照、中文动作、结果、IP 和时间，不包含密码、令牌、正文或查询值。
- 正式 Migration down/up 保留原用户 ID、登录名、密码和角色；回退删除本轮日志，须备份后操作。
- 可选 `ACCOUNT_BROWSER_WS` 连接专用临时 Chrome；测试需要挂载可写 `/tmp/account-artifacts`。页面来自本地 5173，所有 `/api/` 请求转入该隔离 HTTP 服务，验证真实页面与真实后端，不使用生产账号。覆盖双浏览器弹窗／旧端退出、昵称、个人改密、管理员编辑重置、操作日志及 390px 窄屏。

系统日志检查中文类型、级别、事件、结果；原技术代码和上下文保留在详情。操作记录只覆盖到达 API 的请求，不记录本地草稿输入和鼠标动作，健康检查及 `/auth/me` 心跳排除。反向代理后的真实客户端 IP 和真实员工业务使用需要部署后的单独验收。
