### 失败与复测

1. 原型名称表头测试修复前失败（生成 3 个非契约字段），增加自有键校验后通过；不是新版 SheetJS 引入的问题。
2. 初始隔离容器缺少当前 seeds、前端 ESLint ignore/config，导致旧种子断言失败和打包产物被 Lint。改用当前 Dockerfile 构建的完整源码环境后通过，未改密码策略或关闭 Lint 规则。
3. 初始只读挂载下 tmpfs 目录及前端安装目录权限失败；只修正临时容器装配，不修改业务服务权限。旧 API 容器未挂载 vendor，不能用它证明新制品检查；最终在完整新镜像中验证。
4. 新测试的 3 处多余 async 导致 Lint 失败，去除多余 async／使用 Promise mock 后复测；没有削弱规则。
5. Puppeteer 降级候选引入 4 高危依赖告警，已撤销并改用无该依赖链的 Playwright Core；最后审计零告警。
