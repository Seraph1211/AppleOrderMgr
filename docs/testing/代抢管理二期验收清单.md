> 基线：二期需求与实施方案及本次实现工作树

## 隔离和证据

- 只操作主 Agent 指定的独立 Compose 项目、端口和 PostgreSQL；不操作默认开发容器、生产库或真实官网。
- 数据库用例显式检查运行开关、测试库名称和空 `DATABASE_URL`；正式 Migration 建库，不使用 `sync/alter` 代替。
- 浏览器合成 API 与真实 PostgreSQL/API 分开计数；截图检查桌面和 375px 窄屏，自动定位通过不等于目视通过。
- 所有客户、账号、密码和订单为合成。日志与报告不输出模板密码或客户原文。

## 上线反馈补充回归（2026-10-16）

本轮最终口径：专用池未使用/使用中且无活跃占用可自动或手选分配，不需要先重置状态。异常/已下架/普通池排除；确认停抢释放仍保留。历史执行证据见[上线反馈独立验收](../archive/2026-10/2026-10-16-代抢管理上线反馈独立验收.md)。

- 输入：五种身份证标签可输入合法18/15位或既有尾四位；18位验证真实日期和校验码，15位验证结构和19yyMMdd日期，仅提取尾四位，保留0/X；多标签冲突、日期/校验码错误、长度错误、数字类型不静默截尾。原文加密和既有授权展示契约保持。
- 真实 PostgreSQL/HTTP：数字/数字字符串count均按数量分配，非法boolean/数组/对象/空串/零/负数/小数/超过20拒绝且无写入；足池自动/手选、空池保存有assigned数字及assignmentStatus/Message；availableOnly在SQL层筛选后分页，避免不可用前100条遮住后续可用记录。
- UI：375/390/1366/1920px实际点击自动/手选；空池按钮disabled且说明原因；未分配复制禁用并解释；API失败显示在当前遮罩内且清除旧loading提示；剪贴板异步拒绝/缺失进入可选择文本的手动复制窗口，关闭清除临时模板。
- H5：新登记不自动聚焦文本输入；完整预览中的可见文本输入字号至少16px，输入/按钮触控高至少44px；焦点陷阱/Escape恢复、页面滚动锁、表单内滚轮及底部保存可达；缩短视口只验证几何适配，不替代真实iOS软键盘测试。

独立入口：`test/proxyOrdersV2FeedbackInputAcceptance.test.js`、`test/proxyOrdersV2FeedbackAcceptance.integration.test.js`、`test/browser/proxyOrdersV2FeedbackAcceptance.cjs`。数据库门禁和精确命令见当次报告；浏览器支持本地候选制品端口，不访问生产。

## 软删除补充回归（2026-10-16）

删除入口沿用唯一页面权限 `proxy_orders.read`。`POST /api/proxy-orders/:id/delete` 携带正整数 `expectedVersion`；有活跃账号占用时需要 `confirmedStopped=true`。委托仅设置 `deletedAt`，结束当前占用但不改账号状态，保留 Apple 订单、关联、分配和事件历史。

- 真实JWT/HTTP/PostgreSQL：缺少/无效认证401、无权限及同令牌撤权403；非法版本400、陈旧版本409；活跃占用未确认409，确认才结束占用。物理记录、原文、备注、状态、账号状态、Apple订单和links保持；删除/release事件保留操作人。
- 排除边界：已删列表/计数/搜索/详情/资料/所有动作不可访问，单个和混合复制原子拒绝；疑似重复及自动关联不再扫描已删记录。重复删除200+404，只有一次delete事件；删除与分配同版本竞态不留下已删活跃占用。
- 事务与迁移：删除审计失败时标记/版本/占用结束时间全部回滚；正式迁移空表down/up，有软删除历史时拒绝有损down。审计查询显式使用 `ProxyOrder.unscoped()`，不把默认scope不可见误判成物理删除。
- 浏览器375/390/1366/1920px：列表和详情入口、取消不发请求、已释放历史不强制停止确认；活跃占用checkbox门禁、失败保留勾选及遮罩内错误、服务端发现陈旧占用后补回确认、成功清除选中和行/计数、末页唯一记录删除后退回上一页；确认footer和手机触控可达。

入口：`test/proxyOrderDeletionAcceptance.integration.test.js`、`test/browser/proxyOrderDeletionAcceptance.cjs`。固定独立库、命令、截图和执行边界见[软删除独立验收](../archive/2026-10/2026-10-16-代抢管理软删除独立验收.md)。真实外部软件停止只由工作人员确认，合成测试不证明真实任务已经停止。

## 列表展示与状态操作（2026-10-16）

- 核对12个数据列顺序与已确认字段一致；全值、空值、长邮箱／备注、多候选商品、X／前导零身份证后四、创建及更新时间映射正确。
- 城市直接值、历史同城门店推导、缺失／未知／跨城代码占位；邮箱不使用AppleID账号替代。
- 四种状态均显示正确文字与黄／蓝／绿／灰徽章，列表及详情入口可键盘操作；取消不写入，确认发送原版本号，失败保留草稿和反馈。
- 375／390／768／1366／1920px下页面无整体溢出，表格可横滚查看全部列，H5触控44px及输入16px；长内容完整可读。
- 分配／追加、复制／不可复制提示、详情、备注编辑、删除及末页回退仍可操作；账号池表格不受订单列样式影响。
