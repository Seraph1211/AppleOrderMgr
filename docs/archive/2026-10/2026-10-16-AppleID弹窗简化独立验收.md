## 浏览器实测

所有 UI 操作均使用 `cua_repl`，没有另外启动 Playwright 自动化绕过浏览器工具。读取合成 API 审计用于独立核对请求及行状态。

| 用例 | 实际结果 |
| --- | --- |
| 默认打开 | 弹窗内复选框数量 0；状态为“保持原状态”；备注输入框可编辑；未修改时“确认”禁用。 |
| 状态撤销 | 选择“已下架”启用确认，再改回“保持原状态”后确认禁用。 |
| 仅修改备注 | 直接输入两行备注，单击一次“确认”成功关闭；只发送 `notes`，两个原状态分别保留。 |
| 仅修改状态 | 备注从未编辑，状态改为“已下架”；只发送 `status`，之前的两行备注保留。 |
| 清空后取消 | 点击“清空备注”仅显示确认后清空提示，未提前请求；取消后请求数仍为 2，行值未变。 |
| 编辑为空白 | 输入临时文本后替换为一个空格；确认发出 `notes:null`，备注清空且状态保留。 |
| 失败与重试 | 下一次 POST 注入 HTTP 500；弹窗保留原草稿和错误提示，输入与确认可用；再次确认发送相同正文并成功关闭。 |
| 防连点 | 合成 API 挂起响应，对“确认”执行双击，只新增 1 次 POST；保存中字段、清空、取消及保存按钮均禁用。释放响应后成功。 |
| 密保标题 | 详情仅显示“问题 1/2/3”，没有“编码/内容”后缀；值仍为 `130 / 你少年时代最好的朋友叫什么名字？`、`136 / 你的理想工作是什么？`、`142 / 你的父母是在哪里认识的？`；合成答案 `Aa36` 原样显示。 |
| 窄屏 | 实测 CSS viewport 375×811，弹窗字段、清空、取消、确认均可见；可直接输入中文；取消该草稿没有新增请求。测试结束恢复 viewport。 |

冻结的 6 次 `POST /api/apple-ids/batch-update` 正文依次为：

```json
[
  {"ids":[701,702],"notes":"只改备注\n第二行"},
  {"ids":[701,702],"status":"已下架"},
  {"ids":[701,702],"notes":null},
  {"ids":[701,702],"notes":"失败后保留的草稿"},
  {"ids":[701,702],"notes":"失败后保留的草稿"},
  {"ids":[701,702],"notes":null}
]
```

第 4 次注入失败且不写行，第 5 次为人工重试；第 6 次对应双击防护。取消、仅点击清空及无修改没有产生请求。
