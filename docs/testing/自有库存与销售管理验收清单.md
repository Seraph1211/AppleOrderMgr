## 测试环境与文件

现有单元入口为 `npm run test:stock`，包含金额、日期、命令错误分类、导入、附件及预览清理；真实事务入口为 `npm run test:stock:integration`，包含 `test/stock.integration.test.js`、`stockImport.integration.test.js`、`stockLegacy.integration.test.js`。`RUN_STOCK_INTEGRATION=true` 时才运行集成，DB_NAME必须匹配 `^apple_order_mgr_stock_test_[0-9]+$`，DATABASE_URL为空，DB_NAME_TEST与DB_NAME一致；否则立即拒绝，禁止用开发业务库或生产库。先对专用空库执行正式Migration。

浏览器验收连接独立本地测试 API 验证实际保存与重载，设备异常可用明确记录的浏览器 API 模拟；所有 SN、客户、成本和照片均为合成资料。本轮脚本与截图位置见开发记录，主 Agent 的独立 HTTP/UI 证据见[独立验收报告](../archive/2026-10/2026-10-04-自有库存与销售独立验收报告.md)。不能将模拟相机/对象存储/OCR 当成真实硬件或收费服务通过。

## 验证证据与交付门槛

- 单测与隔离DB必须覆盖核心业务逻辑，目标覆盖率>70%；金额、防重复、权限和数据迁移的关键断言不得以快照测试代替。
- 使用现有后端lint、Jest、文档检查、前端lint及Vite构建入口。只格式化任务涉及文件，保留主工作区其他任务；记录原有失败与本次失败，不将跳过标通过。
- 至少提供一次“入库→接单→跨仓挑SN→出货→费用→代理回款”及一次“直发明威→逐台售出→回款”的独立本地API数据库读回证据。
- UI合成测试和本地API联调不能代替真实包装盒扫码、照片识别、真实账户到账、实际仓库盘点或生产验收。真实业务只在明确授权的样本中执行，提供前后记录与独立读回，不以成功提示作为完成证明。
- 发布前备份恢复、只增量迁移、兼容扫码、开关关闭及保留数据的应用回滚需演练；生产迁移、启用与真实导入单独记录授权和结果。

开发完成后逐项填明通过／失败／未执行及证据位置，更新开发进度；本清单保持可复用要求，某次执行证据进入有日期的记录。

## 库存视图页签样式

- 电脑与375px手机短视口：在库／已售／全部同组排列，数量徽标与标签分开；选中状态和键盘焦点清晰，触控高度至少44px，页签不造成整页横向溢出。
- 逐个切换视图并刷新：仅一个页签选中，地址参数、列表记录和计数保持原业务含义；只执行查询，不产生库存、销售或货款写入。

## 固定规格与批量盒标（STOCK-OCR-1004）

- 迁移：16 规格/价格准确，重放不换身份，停用不启用；别名、料号和价格冲突拒绝并回滚；无新事实可回退，有 fixed_catalog 引用拒绝回退。
- 成本：普通录入员新增固定规格后台赋价，显式金额或 null 拒绝；成本读权限投影；原 confirmed 的 amount、priceId、costSource 保留；未知拿货日保持 null。历史补录不改变现货。
- 解析：四种英文色名及 Glacier、拆段描述、容量别名、SKU冲突、未知地区、CMIIT/IMEI/EID/UPC排除、文字不剥S、不猜O/0，条码交叉核对。多盒无法证明关联时人工对应。
- 队列：21图拒绝，每次20图，逐张发起至少6.5秒；429暂停、月额度/未配置停止；失败项显式重试，重复文件/重复SN、100台上限、人工修改保护、取消/迟到/关闭清理。
- 浏览器：PC及375px触屏短视口，逐台改规格、成本、原图预览、移除与确认；实际HTTP保存后读回，registered 身份复用；历史补录分别验收。
- 真实云端：5张会话照片有限技术调用，不保存真实库存记录；2TB只有合成样本，不将其标成实拍通过。

## 2026-10-05 结算与台账操作回归

- 单台售出无批量价区；多台显示“售价”及应用说明，逐台调整仍保存。
- 搜索、筛选、分页不清空已选；查看已选可移除，提交仍检查旧版本及库存状态。
- 在库与已售备注可见、可编辑、可清空，刷新保留；共用实物主档。
- 人员在基础设置按角色预置，售出可选择或手填；停用不删历史引用。
- 结算人工录入，毛利＝结算－官网售价；结算未知、零、负数、超售价、小数精度、重复扣费、资金同步、更正权限均覆盖。
- 正式 Migration 空字段 up/down/up；拒绝非法金额，有结算资料拒绝 down。生产业务恢复库先演练，禁止自动回填历史结算。
- 本地真实 API 的 1440px 和 375px 触控／460px 短视口覆盖保存、跨搜索选择与刷新读回；脚本 `scripts/testStockSettlementBrowser.js` 固定本地专用端口。
