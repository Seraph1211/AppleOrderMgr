## 交付范围

承接[内部接缝与复测记录](2026-09-20-浏览器取数接缝与后续复测记录.md)，本阶段完成管理员任务票据、逐请求全局限流许可、采集结果回传及订单管理行“浏览器刷新”入口。票据与登录 JWT 使用不同用途派生签名密钥，绑定当前账号／登录会话／订单身份／链接摘要／初始版本，120 秒有效；成功写入和随机任务标识审计同事务提交。重复票据即便撞上同一毫秒版本也不能再次成功写入。

Chrome 扩展制品为 `frontend/public/browser-collector.zip`，固定 ID `oghnhnhheeajagnfjmicoicdpokacdmc`；最多 90 秒、100 个请求。只附加自身创建的临时页，正常加载官网，在获得服务端全局时隙后继续请求。正文仅在内存处理，业务字段白名单由服务端源文件统一生成浏览器副本；回传前删除访客令牌、联系资料、付款链接、Cookie 和原始 HTML。跨进程子页尚未支持，发现时停止；没有个人资料复制、会话导出或校验绕过。

服务器默认 `BROWSER_ORDER_REFRESH_ENABLED=false`。现有后台 HTTP 取数行为不变；没有安装扩展或授予浏览器权限。该方案是管理员的本机辅助入口，要求电脑和管理台保持在线；实际 Chrome 调试权限较广，需在安装时明确确认。
