# 身份核验 API 每日额度500次发布

## 需求与实现

用户要求把每员工每日新供应商调用100次提高到500次，沿用原会话的新Worktree、GPT 6.1 Sol／medium子Agent开发与独立测试、Main Review及自主提交发布授权。每分钟50次与确定结果600秒复用保持，不重置当日已用次数；旧Token继续有效。无数据库Migration。

执行层日额度常量改为500，元数据直接引用该常量；页面读取元数据上限，复制说明同步500。管理员列表最多100条属于分页保护，保持原值。

## Review与隔离验证

Main审查范围仅API两份service和前端一份说明工具，确认原子预占、按员工计数、北京时间日期、复用／旧Excel规则保留。独立验证4套Jest55项通过，前端复制5项、1440／375px浏览器、lint／构建／文档检查通过。后端lint0错误及5790项既有warning，前端0错误／14项既有warning。

边界测试先正常调用1次、在合成PG中把计数预置499，再真实HTTP验证第500次成功且数据库读回500，第501次429 DAILY_LIMIT及Retry-After；该例实际mock供应商2次，未顺序发500次。重置后计数保留500、旧Token401、新Token仍受限、旧结果仍可复用；两个事务争抢最后一次仅一个成功。模拟北京时间午夜后新日1、前日500，599秒复用／601秒重验及旧Excel不受API日额度影响通过。真实供应商调用0次。

证据目录`.tmp/daily500/`；Main边界复验日志`主审额度边界复验.log`。发布配方见[本轮制品白名单](../../../scripts/releases/20261016-identity-daily500/README.md)。
