# 库存监控开发验收

> 状态：本地开发验收通过，2026-10-02。真实库存稳定性和企微群收件未验收。

## 库存有界并发回归

- 正常最多 3 请求在途，恢复探测单并发；并发不放大 1 RPS 发起预算、小时／日次数、字节、代理端点或重试预算。
- PostgreSQL 验证一个轮次拥有者、最多三个不同任务、每项令牌与到期时间、乱序／重复结算去重；到期停止领取并等待已有结果，旧任务不因新任务续租复活。
- 重叠地域失败不覆盖本轮有效组合；容量等待不计作真实失败；样本、事件与通知不重复。
- 请求闸门验证多实例并发预占、各自字节结算、重复结算幂等、未知到期保守计费、跨日不退款到新日、验证工具互斥。
- 保护触发后旧请求成功不能成为恢复成功；代理提取合并。实际轮次耗时与在途峰值上线单列，合成测试不代表真实代理性能。

## 2026-10-03 运行提醒降噪

- 根因：单次请求异常和下一次成功都直接排队，旧健康消息没有发送前复核，导致短时 degraded/normal 反复通知。
- 策略测试：普通故障连续 2 分钟、稳定恢复 2 分钟、同类 30 分钟合并、严重故障立即排队；已提醒故障才产生恢复，未知回执不重复发送，明确失败不会产生孤立恢复，目标切换／关闭及重启持久化。
- 真实隔离 PostgreSQL：多 Worker 并发只排一条、发送前成功则撤销旧异常、旧版本待发队列清理、恢复一次、严重故障绕过普通故障合并窗口、静默／过期／中断未知处理；到货规则继续回归。
- 无表结构变化，沿用 JSONB 可选版本字段，不执行 Migration。生产采集保护、限流、预算及开关保持原配置；合成发送使用 mock，不向真实群发测试消息。
- 已通过全量 81 套／905 项、隔离数据库 25 项和策略 12 项；生产短时观察出现 2 次读取失败后恢复，未新增健康消息。证据与边界见[降噪发布记录](../archive/2026-10/2026-10-03-库存运行提醒降噪发布记录.md)。

## 2026-10-03 故障与权限拆分回归

- 现象与根因：精确 SKU 下钻缺少筛选标签映射导致空白；一次 CONNECT 502 被作为永久出口拒绝，后续 NO_HEALTHY_PROXY 又被通用覆盖错误替换。
- 修复：SKU 摘要安全处理；CONNECT 502/503/504 纳入既有有限重试／异常冷却，其他代理拒绝与目标风控保持原保护；失败快照保留原因及上次有效值。
- 权限：新增 `inventory.read` 可逐人授予。6 个只读 GET 入口允许显式授权用户；11 个管理端点拒绝普通用户；匿名和无权限用户拒绝。scope 仅返回白名单字段。
- 页面：两个菜单路由，分别包含三个用户查询页签与两个管理员配置页签；旧 tab 链接兼容且重新鉴权；普通用户不请求管理配置／健康。已启用商品和门店有可展开名单，配置与运行状态分别展示。
- 已通过：后端全量 80 套／893 项、隔离 PostgreSQL 23 项；CONNECT 临时错误与冷却回归包含在全量测试中。浏览器新增精确 SKU “查看记录”请求参数与无崩溃检查，覆盖五种视口、授权／未授权普通用户与管理员。
- 已发布生产；管理员真实页面历史下钻、两组菜单及 32 商品／49 门店名单可见。首个恢复自动轮次 1568/1568、失败 0，详见[发布记录](../archive/2026-10/2026-10-03-库存故障与权限分组发布记录.md)。本地合成测试与本次有限观察不代表长期代理稳定性或通知群收件验收。
