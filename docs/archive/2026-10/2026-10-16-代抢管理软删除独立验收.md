## 契约与环境

`POST /api/proxy-orders/:id/delete` 采用唯一页面权限 `proxy_orders.read`、正整数 `expectedVersion`。有活跃账号占用时必须 `confirmedStopped=true`；只软删除委托、结束活跃占用并记录事件，不改变账号状态，不删除 Apple 订单、关联或历史。

独立库 `apple_order_mgr_proxy_delete_acceptance_20261016`，隔离 PostgreSQL 15/`apple-proxy-v2-postgres-1`、API `apple-proxy-v2-api-1`；从空库执行全部正式 Migration，包含 `20261016000001-soft-delete-proxy-orders.js`。运行门禁 `RUN_PROXY_DELETE_ACCEPTANCE=true`、固定 `DB_NAME=DB_NAME_TEST`、空 `DATABASE_URL`。不使用生产或开发 Agent 的测试库。

HTTP 用例启动临时 Express，调用真实 `authenticate`、JWT、UserPermission、Router、Service、PostgreSQL。所有用户、会话和订单均为合成数据。浏览器采用宿主 Chrome headless / Playwright，所有 API 合成拦截且外部请求阻断，前端仅本地 `http://127.0.0.1:5373`。
