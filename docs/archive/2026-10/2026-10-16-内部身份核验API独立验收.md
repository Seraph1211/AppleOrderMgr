## 发现及复测

1. 首轮真实 SQL 发现额度 INSERT 的 `:limit` 前缺少替换词法空格，导致正常 API 503；开发修复后全部新核验用例通过。
2. 真实 Nginx 发现畸形 URI 的早期 400 缺少缓存／Referer 响应头；开发补服务器级 always 头后严格复测通过。
3. 新全局暂停使旧 fatal 回归必须管理员恢复才能继续 pending；回归已补“阻断→管理员恢复→继续”证据，错误行不重试。
4. 默认全量最初缺少既有官网预检测试专用数据库别名，补独立临时数据库后 4 项环境失败消失；未改业务代码绕过检查。
