- 已确认需求：新订单继续由邮件提供订单号和链接；未付款或支付状态未知的订单每分钟刷新；已付款订单停止定时刷新，只在打开订单页面或人工操作时刷新；人工操作支持单个和全部订单。
- 完成实现：新增逐订单调度、刷新任务、全量批次和 Worker 单例状态四张表及 Migration；独立 Worker 使用 PostgreSQL 租约与 `FOR UPDATE SKIP LOCKED` 领取，支持任务合并、优先级提升、过期租约恢复、持久化暂停和全局请求时隙。
- 接口与前端：单笔、指定批量、刷新全部和页面打开均改为异步提交；新增任务/批次查询。订单列表和详情返回新鲜度与活动任务，前端展示待付款筛选、排队/刷新/最新/过期/失败及全量批次进度，不把“任务提交”显示为“官网已更新”。
- 代理与兼容：新增 `kdl_tunnel`/`kdl_private` Provider。Apple 订单入口存在跨域重定向，快代理默认“每 HTTP 请求换出口”会让同一次抓取的首跳和重定向使用不同 IP；隧道模式现为每次尝试生成独立 `sid`，用 `period-0.5` 固定出口 30 秒，下一次重试再换出口，并使用兼容性优先的 `type-std`、质量优先的 `pool-q10`、`Connection: close` 和 `Accept-Encoding: gzip`。自定义 `HttpsProxyAgent` 对照实验没有提高成功率，继续使用 Axios 原生代理配置。新增 517 建链错误分类，541 断路改为仅在连续订单均耗尽三次 541 后累计，单订单重试成功不会暂停全局 Worker。环境示例只保留占位符，试用密码未写入仓库或日志。
- 解析兼容：订单状态以首个订单项的 `currentStatus` 为第一权威来源，兼容真实的 `orderItem-1of2-*` 键；已验证 `PICKED_UP → completed`、`PAYMENT_EXPIRED_STORED_ORDER → cancelled + unpaid`，未知枚举才回退到清理后的可见文本。支付状态不再扫描隐藏脚本、隐藏节点和页脚中的退款说明。官网没有总计标签和金额时记为“未提供”，只有明确出现总计标签但无法解析才记录解析错误。
- 开发自测：爬虫相关 4 个 Jest 套件、41 个测试通过，`crawlerService` Functions 覆盖率 72.72%，快代理 Provider Lines 覆盖率 87.5%；后端全量 28 个套件、151 个测试通过，另有 1 个集成套件/12 个测试按环境门禁跳过。后端全仓 Lint 0 error/743 warning；前端 Lint 0 error/52 warning；Vite 构建成功，主包 815.38 kB/gzip 233.78 kB 并保留大包警告；47 份文档全部可达，11 个模型字段覆盖检查通过。隔离库全量 Migration 及 `up → down → up`、并发领取和 300 单调度验证沿用本轮前序证据。
- 真实订单只读验证：83 条链接格式均有效。初始“每 HTTP 请求换出口”策略按 1 RPS、单订单最多 3 次成功 49/83、失败 34/83；失败是抓取失败，不是 HTML 解析失败，主要为 HTTP 541，另有 HTTP 200 后响应流中断、连接重置、超时和一次 517。改为 30 秒固定出口且每次重试换 `sid` 后，`type-std + pool-q10` 的 83 条复测首次/第二次/第三次成功为 44/18/9，共成功 71/83、失败 12/83，身份不匹配 0；失败尝试包含 52 次 HTTP 541、9 次 HTTP 200 响应流中断、6 次连接重置、4 次超时和 1 次 HTTP 517。增强池的 34 条对照仅恢复 24 条，低于标准池；自定义 Agent 的 4 条样本对照也无收益，因此没有采用。真实稳定性验收仍未通过。
- 真实页面结构：对真实已取货页的可见 HTML 标签和内嵌订单 JSON 分别分析，确认 `currentStatus=PICKED_UP`、“已收到付款/已取货”可见，而“退款”仅来自隐藏内容；页面确实可能不提供金额。另一个真实样本出现 `PAYMENT_EXPIRED_STORED_ORDER`。最终解析器已用真实结构样本和合成回归验证，但 71/83 网络批次发生在最后一次订单项键兼容修复之前，因此只作为 Fetch/身份与代理稳定性证据，不把该批次的解析统计作为最终业务数据证据。
- 边界：真实链接只通过禁用业务日志的临时只读验证进程访问，未保存 HTML、JSON、完整链接或个人信息；临时诊断脚本和容器副本已删除。未启动邮件或爬虫 Worker，未修改当前开发库或生产库，未执行真实订单写库、生产 Migration、部署、重启、commit 或 push。Parse、Validate、Persist 的物理拆分、脱敏 HTML Fixture、真实 API/浏览器交互、真实退货枚举、83 条最终解析版全量复测及一分钟时效仍待后续验证。
